# Pramodh Grocery — Shopify Theme

## How to install
1. In Shopify Admin, go to **Online Store > Themes**.
2. Click **Add theme > Upload zip file**, and upload `pramodh-theme.zip`.
3. Click **Customize** on the new theme to open the theme editor.

## What's included
- Home page: hero slideshow, category icon grid, trust/features bar,
  "Best Sellers" product row, "Weekly Offers" promo banner, "Shop by Brand" strip.
- Product page with image gallery, variant picker, quantity selector, AJAX add-to-cart.
- Collection page with sorting + pagination.
- Cart page + slide-out cart drawer.
- Search, 404, list-collections (Shop by Category), contact form, customer
  login/register/account pages.
- Every homepage section is drag-and-drop editable in the theme editor —
  add/remove/reorder slides, categories, features, brands, etc.

## First things to set up in the theme editor
1. **Theme settings > Logo**: upload your Pramodh logo (or leave blank to show
   the styled text logo using your brand colors).
2. **Theme settings > Colors**: already pre-filled with the green / red / gold
   palette from your reference design — adjust as needed.
3. **Header section**: set your default delivery postcode.
4. **Home page sections**: replace sample images/text in the Hero slideshow,
   Category grid, Best Sellers (pick a real collection), Promo banner, and
   Shop by Brand blocks.
5. **Navigation**: go to Online Store > Navigation and build your "Main menu"
   with links/dropdowns for Fresh Vegetables, Fruits, Rice & Grains, etc. —
   the header automatically pulls this in.
6. **Pages**: create Pages for About Us, FAQs, Shipping & Returns, Track Order
   — the `page.contact` template is auto-used for a page titled/handle "contact".

## Notes
- Fonts: Baloo 2 (headings/logo) + Poppins (body), loaded from Google Fonts,
  chosen to match the rounded bold style of your uploaded logo reference.
- The theme uses Shopify's modern JSON templates (Online Store 2.0), so every
  page is section-based and fully customizable without touching code.
